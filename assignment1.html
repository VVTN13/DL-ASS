Problem statement

We classify a single 28×28 grayscale clothing image into one of 10 product categories (T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, Ankle boot). The same kind of task appears in retail catalogues, where product photos need to be sorted automatically.

  • Input: one 28×28 grayscale image, raw uint8 pixels 0–255.
  • Output: 10 class logits, and the predicted label is the argmax.
  • Prediction unit: one image.
  • Main difficulties: low resolution and no colour; upper-body garments (T-shirt, Pullover, Coat, Shirt) have very similar silhouettes; there is noticeable variation within each class.

Dataset description and EDA

Fashion-MNIST (Zalando, MIT license) is the main comparison dataset. We load it with torchvision.datasets.FashionMNIST. It has 60,000 official training images and 10,000 official test images. MNIST is used only for debugging.

All five models return raw logits because CrossEntropyLoss computes log-softmax and negative log-likelihood internally. The image and sequence representations are already implemented in a1/data.py for the M2 models.

The custom CNN uses two 3×3 convolutions with shared local filters. Each produces feature maps, followed by ReLU and 2×2 max pooling. The resulting 64×7×7 features feed a small classifier. It is trained from scratch and returns raw logits. See the CNN experiment notes for layer shapes and explanations.

LSTM: image-to-sequence representation

Each normalized image has shape (1, 28, 28). Removing the channel axis gives (28 steps, 28 features): step 1 is the top row's 28 pixels from left to right, step 2 is the next row, and step 28 is the bottom row. All 784 pixels remain. A batch has shape (B, 28, 28), where the second axis is ordered rows and the third is pixel features. The exact mapping is S[b, r, c] = Z[b, 0, r, c]. The steps describe spatial order in a static image.

One forward LSTM layer carries 128-value hidden and cell states between rows of each image. Its gates learn which earlier information to keep, write and expose. The states start at zero for each image and are never shared between images or batches. After all rows, the final hidden state h_n[-1] feeds Dropout(0.2) and Linear(128, 10), producing raw logits. Dropout is disabled for evaluation. See the LSTM notes for layer shapes, parameter calculations, checks and limitations, and the PyTorch LSTM reference for state and gate definitions.

Transformer: image-to-patch representation

Each normalized image is divided into a 7×7 grid of non-overlapping 4×4 patches. Patches run left to right, then top to bottom; pixels within each patch follow the same order. The batch shape is (B, 49 patches, 16 pixels). With zero-based indices, P[7r+c, 4i+j] = Z[0, 4r+i, 4c+j], where r,c=0..6 and i,j=0..3. All 784 pixels are retained exactly once.

A shared Linear(16, 64) projects each patch, and learned position vectors identify its location. Two pre-norm encoder blocks use four attention heads and GELU feed-forward layers (64→128→64). All patches in an image can attend to each other. Final LayerNorm and mean pooling produce 64 features; dropout and Linear(64, 10) return raw logits. Dropout is 0.2 and is disabled for evaluation. The model is trained from scratch, with no class token, padding or causal mask. Sequence-first encoder internals avoid a measured fused CUDA inference discrepancy; see the Transformer notes for shapes, parameter counts, the numerical correction and reproduction commands.

Comparison and discussion

The CNN has the highest measured test accuracy (91.94%) and macro-F1 (0.918886). It makes 378 fewer errors than MLP, a 3.78-percentage-point accuracy improvement, and 768 fewer than Linear. Local convolution filters and pooling provide a plausible advantage for clothing silhouettes, but the CNN also has about 1.79 times the MLP's parameters. Architecture and capacity change together, so this comparison does not isolate the contribution of spatial weight sharing.

The CUDA MLP improves on Linear by 3.90 test accuracy points and 0.039081 macro-F1, reducing errors from 1,574 to 1,184. Its hidden nonlinear layers accompany about 30 times as many parameters. Validation loss selects epoch 9 for both baselines. LSTM exceeds MLP by 32 correct test predictions (88.48% versus 88.16%). One seed does not establish a stable ranking. LSTM uses about 35% of the MLP's parameters, while the MLP's recorded CUDA forward pass is shorter.

Transformer test accuracy is 6.39 points below CNN and 2.93 below LSTM, while exceeding Linear by 1.29 points. It has the fewest parameters among the nonlinear models (71,946), yet the longest recorded CUDA forward time and training time among CNN/LSTM/Transformer. Attention over 49 tokens adds computation that parameter count alone does not describe. These results apply to this small model trained from scratch for ten epochs; they do not establish that attention or patch representations are generally inferior. No architecture or hyperparameter was selected using test accuracy.

CNN test accuracy is 3.46 percentage points above LSTM (91.94% vs 88.48%). The LSTM has about 19.5% of the CNN's parameters but took longer to train in these individual runs (122.12 s vs 105.03 s). Fewer parameters do not remove the cost of reading 28 dependent steps. Rows preserve horizontal feature positions but impose a top-to-bottom order and summarize earlier rows in a fixed state. CNN filters share weights across local image neighborhoods. The CNN's final training loss (0.1289) is below its validation loss (0.2001), so it also shows a generalization gap. Linear has the smallest parameter count and shortest recorded forward time; MLP offers higher accuracy while remaining faster in this batch timing than the three M2 architectures. Forward time per image is amortized over 128 images and does not measure single-image latency. Loading and other evaluation work also affect the full test-pass times, which need not have the same order as forward-only times.

CNN errors

The CNN makes 806 test errors. Shirt has the lowest recall (71.8%) and F1 (0.7518). Of 1,000 true shirts, 103 are predicted as Coat, 95 as T-shirt/top and 47 as Pullover. There are also 94 true T-shirt/top images predicted as Shirt. These errors support the EDA observation that upper-body garments are difficult to distinguish at this resolution. High confidence can still be wrong: test image 902 is a Sandal predicted as Ankle boot at 96.7% confidence.

LSTM errors

The LSTM makes 1,152 test errors. Shirt has the lowest recall (61.8%) and F1 (0.6784). Of 1,000 shirts, 181 become T-shirt/top, 83 become Coat and 80 become Pullover. Pullover/Coat confusion appears in both directions (87 and 77 images respectively). Trouser recall is 97.0% and Bag recall is 96.9%. These are measured counts from the selected checkpoint.

Transformer errors

The selected Transformer makes 1,445 test errors. Shirt has the lowest recall (48.9%) and F1 (0.5920); among its 1,000 examples, the largest confusions are 178 as T-shirt/top, 153 as Coat, 131 as Pullover. Upper-body garments remain difficult to separate. The largest individual off-diagonal count is Pullover predicted as Coat (205 images), compared with 65 coats predicted as Pullover. Coat recall is 88.0%, but precision is only 66.6% because other garments are often assigned to Coat. Trouser recall is much higher (97.3%), so the overall score hides a pronounced class difference.

In the sampled errors, image 5255 is a Coat predicted as Pullover at 95.9% confidence, and image 976 is a Pullover predicted as Coat at 88.1%. Both show similar light, long-sleeved outlines; these examples illustrate the confusion seen in the full matrix. Fixed patches, mean pooling and a short training budget are possible factors to study, but this experiment does not identify the cause. Despite higher overall accuracy than Linear, the Transformer misses 77 more shirts. Its 75.0% Shirt precision and 48.9% recall show that a relatively precise Shirt prediction still leaves many true shirts unrecognized.

Linear errors

Linear makes 1,574 test errors. Shirt has the lowest recall (56.6%) and F1 (0.5859). Of 1,000 shirts, 166 are predicted as T-shirt/top and 112 as Pullover. There are also 127 coats predicted as Pullover, 108 pullovers predicted as Shirt and 106 coats predicted as Shirt. Shirt precision is only 60.7%, so both missed shirts and false Shirt predictions contribute to its low F1. In contrast, Ankle boot recall is 96.1% and Trouser recall is 95.5%. A single linear classifier handles these classes much better than the overlapping upper-body categories.

Sampled images 7683 and 5222 are coats predicted as Pullover at 53.5% and 56.9% confidence; their long-sleeved outlines look similar at this resolution. Image 979 is a Dress predicted as T-shirt/top at 98.6%, showing that even high softmax confidence can accompany a mistake. Flattening retains all pixels, but the classifier has no hidden nonlinear layers or shared local filters. These architectural limits are consistent with the observed errors; the images alone do not prove their cause.

MLP errors

The CUDA MLP makes 1,184 errors. Shirt has its lowest recall (63.7%) and F1 (0.6838). It predicts 177 shirts as T-shirt/top and 64 as Pullover, and 71 coats as Pullover. It makes 390 fewer errors than Linear; 759 errors occur between the four upper-body labels. Architecture and capacity change together, so this does not isolate nonlinearity.

Image 4159 is Pullover predicted as T-shirt/top (84.0% confidence). Image 930 is T-shirt/top predicted as Shirt (52.8% confidence). Image 7442 is Pullover predicted as Coat (55.4% confidence). Softmax confidence is uncalibrated.

Limitations and conclusion

  • One seed and one validation split give no estimate of training variance or statistical significance; the 32-image MLP/LSTM difference needs repeated-seed evaluation.
  • The same ten-epoch Adam budget supports a controlled protocol, but does not establish that each architecture is equally well tuned or converged. Parameter counts, representations and architectures also differ.
  • All training and inference timings use CUDA on the same GTX 1660 SUPER, but come from separate sessions without repeated-session uncertainty estimates.
  • The LSTM reads rows in one direction and the Transformer uses fixed 4×4 patches and mean pooling. Alternative sequence orders, patch sizes, pooling methods and training schedules have not been compared.
  • Softmax confidence is uncalibrated. Fashion-MNIST is balanced and standardized; performance on real retail photos, colour images or shifted distributions has not been tested.

Under the recorded protocol, the CNN is the strongest model for predictive accuracy: 91.94% test accuracy, 0.918886 macro-F1 and 806 errors. It improves accuracy by 7.68 points over Linear, 3.78 over MLP, 3.46 over LSTM and 6.39 over Transformer. For this experiment, it is the preferred model when accuracy is the main criterion. Linear provides the smallest and fastest measured forward pass, while MLP reaches 88.16% accuracy with a shorter forward time than CNN. LSTM achieves similar accuracy to MLP with fewer parameters. The small Transformer improves on Linear overall, but does not surpass the other nonlinear models within this training budget.

Across all five models, Shirt and the related upper-body categories remain the main source of errors. The next experiments should repeat seeds, compare training on one machine, and use validation data to assess augmentation, sequence/patch choices and confidence calibration. These are follow-up proposals, not measured improvements. The final test results reported here belong to the validation-selected checkpoints; further tuning should keep test data out of model selection and use a fresh held-out evaluation for new generalization claims.
