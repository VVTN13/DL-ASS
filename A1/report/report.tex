\section*{Abstract / Executive Summary}
\addcontentsline{toc}{section}{Abstract / Executive Summary}
This assignment studies the classification of low-resolution clothing and accessory
images using five neural network configurations: a linear classifier, a multilayer
perceptron (MLP), a convolutional neural network (CNN), a row-sequence long
short-term memory network (LSTM), and a patch-based Transformer. The central
question is how these different input representations and model structures compare
when they share the same data partition, preprocessing, and nominal training budget.

This first report stage establishes the problem and the dataset evidence needed
for that comparison. Fashion-MNIST provides 60,000 official training images and
10,000 official test images, each with 28 by 28 grayscale pixels and one of ten
labels. A seed-42 stratified split produces 54,000 training and 6,000 validation
images. Every class contributes 5,400 training, 600 validation, and 1,000 test
examples. Descriptive analysis uses the training subset; validation and test data
are used here only for structural checks and an exact-duplicate audit.

Across all 42,336,000 training pixels, the raw mean is \RawMean{} and the population
standard deviation is \RawStd{} on the 0--255 scale. Exactly \ZeroPercent\% of
training pixels are zero, while \BlankImages{} training images are entirely zero.
Class-specific brightness, spatial averages, and variability maps reveal
substantial differences in silhouette and image coverage. Similarity between
upper-body garment prototypes motivates later class-specific error analysis;
these descriptive similarities do not determine a trained model's performance.

The preprocessing pipeline uses a training-only mean of \TrainMean{} and
standard deviation of \TrainStd{} on the 0--1 scale. The same normalized pixels
are exposed as vectors, image grids, row sequences, or patch sequences without
discarding information. CUDA reductions were executed on the local GTX 1660 SUPER
and checked against CPU calculations. This document completes Sections 1 and 2.
Methodology, matched CUDA experiments, model results, and conclusions belong to
subsequent stages and are specified in the accompanying continuation guide.

\vspace{.4em}
\textbf{Keywords:} Fashion-MNIST; image classification; exploratory data analysis;
training-only normalization; CUDA; reproducibility.
